## Projects I'm proud of

### 🌲 NIRANTAR — AI Research Discovery Platform

During my internship at ICFRE, I worked on an AI-powered platform for discovering forestry research more effectively.

The project combines semantic and keyword-based search to make a large research collection easier to explore.

* Built search using sentence embeddings, FAISS, and BM25
* Added metadata-based indexing for more relevant results
* Worked with a collection of **28K+ forestry research records**
* Explored knowledge graph visualisation and intelligent recommendations

---

### 💳 Digital Wallet

A full-stack digital wallet project focused on secure transactions and basic fraud monitoring.

* Implemented JWT-based authentication
* Used bcrypt for password protection
* Added deposits, withdrawals, and transfers
* Built role-based access control
* Added rule-based fraud detection
* Created REST APIs with MongoDB integration

---

### 🩺 ML Health Guard

A machine learning application for exploring disease prediction using structured health data.

* Used SVM and Logistic Regression models
* Built prediction workflows for diabetes and Parkinson's disease
* Worked on preprocessing and feature engineering
* Created an interactive interface for predictions
